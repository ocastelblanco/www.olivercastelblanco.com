# Objetivos y alcances

## Objetivos

Crear un sitio web con un look profesional que refleje mis capacidades técnicas y de desarrollo de soluciones integrales, desde la arquitectura y el diseño, apoyadas en la orquestación IA.

A la vez, este sitio web debe servir como modelo de desarrollo apoyado en LLM. Por lo tanto, es indispensable que se registre todo el proceso, a manera de bitácora técnica, para que haga parte fundamental del sitio web.

El sitio web debe tener un SEO dirigido a IA, que le permita ser descubierto e indexado por motores de búsqueda y modelos de lenguaje IA.

## Alcances

El sitio web debe ser construído en Angular 22 / SSR, y será desplegado como una función de AWS Lambda, usando Serverless (última version estable).

Se usará AWS S3 para almacenar los activos digitales necesarios, usando el subdominio `https://cdn.ocastelblanco.com` y haciendo uso de AWS CloudFront como CDN.

En general, se usará la infraestructura de AWS y de Google Firebase.

Se usará Github Actions para crear un flujo de CI.
