# Project Brief: ARCH_ORCH // Solutions Architect Portfolio

## 1. Project Overview
**ARCH_ORCH** is a high-fidelity, technical portfolio for **Oliver Castelblanco**, a Solutions Architect and AI Orchestrator. The project aims to showcase technical expertise through an "Industrial Minimalism" aesthetic, blending high-performance data visualization with a premium hardware-inspired interface.

## 2. Brand Identity
*   **Brand Name:** OLIVER CASTELBLANCO // ARCH_ORCH
*   **Domain:** ocastelblanco.com
*   **Visual Philosophy:** Industrial Minimalism / Technical Dark Mode.
*   **Core Values:** Precision, Scalability, Performance, and Transparency.

## 3. Design System Specifications
*   **Color Palette:**
    *   **Background:** Deep Charcoal (#121212) with a subtle noise texture.
    *   **Primary Accent:** Cyber Lime (#CCFF00) - Used for primary CTAs and critical status indicators.
    *   **Secondary Accent:** Electric Cyan (#00F0FF) - Used for technical highlights, metrics, and interactive elements.
    *   **Surface:** Zinc-950/900 for card backgrounds and elevated surfaces.
*   **Typography:**
    *   **Headings & Data:** JetBrains Mono (Technical, Monospaced).
    *   **Body Text:** Inter (Semi-bold, maximum legibility).
*   **UI Components:**
    *   **Expandable Sidebar:** 20px outline icons, expanding to full labels on hover.
    *   **Metric-First Cards:** Borderless, 10% white opacity glassmorphism with Cyber Lime glow on hover.
    *   **CLI Terminal:** Integrated command-line interface for inquiries and contact.

## 4. Key Screen Definitions
1.  **Landing Page:** High-impact hero section with "Core Directives" (Cloud Architecture, AI Orchestration, etc.).
2.  **AI Orchestration Pipeline:** Deep dive into system architecture, execution flows, and real-time performance metrics (Latency, Throughput, Uptime).
3.  **Project Registry:** A 'Metric-First' grid showcasing specific deployments with key performance indicators (KPIs) front and center.
4.  **Case Studies (Deployment Logs):** Detailed archive of infrastructure reviews and optimization projects.
5.  **System Terminal:** A functional CLI-inspired contact portal for direct inquiry.

## 5. Technical Requirements
*   **Accessibility:** All components must pass WCAG 2.2 AA contrast standards.
*   **Responsive Shell:** Unified sidebar and top-bar navigation across all views.
*   **Interactions:** Mechanical-snap transitions, 0ms-75ms response times, and high-contrast hover states.
